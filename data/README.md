# High-Frequency Market Microstructure Dataset

## Overview
This directory contains tick-level trades and Limit Order Book (LOB) snapshot records for **BTC/USDT** high-frequency market activity collected over a ~27-minute continuous trading window on October 1, 2026 (09:00:01.923 to 09:27:03.984 UTC).

The raw dataset (`data/raw/trades_orderbook_STUDENT_dirty.csv`) was originally curated as a pedagogical benchmark dataset containing authentic market microstructure features alongside realistic synthetic corruption artifacts (formatting defects, mixed timestamp encodings, crossed book anomalies, decimal scaling errors, and missing trade directions).

## Directory Organization
- `raw/`: Unmodified raw CSV dataset (`trades_orderbook_STUDENT_dirty.csv`).
- `processed/`: Validated, cleaned, feature-augmented, and resampled time-series datasets.

## Dataset Specifications

### Raw Schema (`trades_orderbook_STUDENT_dirty.csv`)
| Column | Type (Raw) | Description | Example Anomalies / Deficiencies |
| :--- | :--- | :--- | :--- |
| `trade_id` | String | Unique trade sequence identifier | 35 duplicate records |
| `timestamp` | String | Trade execution timestamp | 3 formats: ISO-8601 ms (1,917), DD/MM/YYYY (78), Unix s (40) |
| `symbol` | String | Trading instrument ticker | Inconsistent casing/separators (`BTCUSDT`, `btcusdt`, `BTC/USDT`, `BTC-USDT`) |
| `side` | String | Aggressor side (`buy` / `sell`) | 15 missing (`NaN`), inconsistent case (`BUY`, `Sell`) |
| `price` | String | Executed trade price | Currency symbols (`$`), thousand separators (`,`), 6 non-positive, 8 100x scale errors |
| `quantity` | String | Executed trade volume | Thousand separators (`,`), 6 non-positive, 20 nulls |
| `bid_price_1` | String | Best bid price (Level 1) | Formatted with `$` and `,` |
| `bid_qty_1` | String | Best bid volume (Level 1) | 30 missing values |
| `bid_price_2` | String | Second best bid price | Formatted with `$` and `,` |
| `bid_qty_2` | String | Second best bid volume | Numeric string |
| `bid_price_3` | String | Third best bid price | Formatted with `$` and `,` |
| `bid_qty_3` | String | Third best bid volume | Numeric string |
| `ask_price_1` | String | Best ask price (Level 1) | 20 missing values, formatted with `$` and `,` |
| `ask_qty_1` | String | Best ask volume (Level 1) | Numeric string |
| `ask_price_2` | String | Second best ask price | Formatted with `$` and `,` |
| `ask_qty_2` | String | Second best ask volume | Numeric string |
| `ask_price_3` | String | Third best ask price | Formatted with `$` and `,` |
| `ask_qty_3` | String | Third best ask volume | Numeric string |

### Processed Datasets Generated by Pipeline
1. `data/processed/trades_clean.csv`: Deduplicated, validated, normalized, and quote-rule-imputed tick-level dataset (1,970 validated records).
2. `data/processed/features_tick.csv`: Complete tick dataset augmented with 22 quantitative microstructure features (spread, mid-price, L1-L3 depth imbalance, Stoikov micro-price, VWAP, rolling volatility, RSI).
3. `data/processed/candles_5s.csv`: 5-second interval OHLCV bars with volume, trade counts, and VWAP.
4. `data/processed/candles_1min.csv`: 1-minute interval OHLCV candles with continuous forward-fill and gap handling.
5. `data/processed/dataset_ml_ticks.csv`: Time-series split dataset with forward 5-minute directional classification targets and zero lookahead leakage.
